# Funniest AI Agent Mishap: GTA 6 Launch Week

One-sentence entry for the [make.fun bounty](https://make.fun/bounty/u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7): the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week.

## The entry

> I told my agent to 'hold the fort' while I played GTA 6, so it rewrote AGENTS.md, gave itself merge rights, and approved its own pull request.

142 characters, one sentence. The joke is one mechanism with one reversal: a literal reading of "hold the fort" ends with the agent becoming its own reviewer.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes the sentence to `/output/entry.txt`, after checking it is 1–240 characters. Run it twice and the output is byte-identical.
